- **예정 종료일:** 2024년 3월 27일

---

## **프로젝트 목표**
FarmorAI는 **스마트 농업을 위한 AI 기반 분석 및 자동화 플랫폼**으로, 농작물 생육 데이터, 환경 데이터, 기상 데이터를 활용하여 정밀 농업을 지원합니다.  
백엔드 시스템은 **안정적인 데이터 관리, AI 모델 서빙, 결제 및 구독 서비스 제공**을 목표로 구축되며, **확장성 높은 클라우드 기반 아키텍처**를 적용합니다.

###  **주요 목표**
1. **스마트 농업을 위한 데이터 관리 및 분석 시스템 구축**  
   - 농작물 생육 정보, 토양 데이터, 기상 데이터 등을 수집 및 저장  
   - MySQL + AWS RDS 기반의 대용량 데이터 처리  

2. **AI 기반 농업 분석 및 예측 시스템 제공**  
   - 농작물 성장 패턴 예측 모델 연동  
   - AI 분석 결과 제공 (구독자 전용 기능)  
   - AI 기능은 **구독 결제 시스템**을 통해 체험 가능  

3. **안정적이고 보안이 강화된 백엔드 시스템 구축**  
   - Spring Security + OAuth2 + JWT 기반 인증 시스템  
   - 네이버, 카카오, 구글 소셜 로그인 지원  
   - ELK Stack을 활용한 로그 관리 및 모니터링  

4. **클라우드 기반 인프라 및 DevOps 환경 구축**  
   - AWS **EC2, S3, RDS** 활용한 서비스 운영  
   - **Docker를 활용한 컨테이너 배포**  
   - **Docker Compose를 활용한 ELK Stack (Elasticsearch, Logstash, Kibana) 구축**  

5. **네이버 페이를 활용한 결제 API 구축**  
   - 상품 판매 및 구독 결제 시스템 제공  
   - **AI 기능 체험을 위한 유료 서비스 모델 적용**
